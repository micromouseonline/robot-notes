# Wall Sensor Geometry


!!! Note "Outline"

    The sensor data collected may be contaminated by noise which must be reduced or removed. Simple software filters can deal with many types of noise and are not hard to implement.

    Other kinds of filtering of the sensor results can provide additional information to the rest of the software. Edge detection is a common requirement which can be very easily performed with basic filtering techniques.
